# DriveNow Car Rental System

A React + Vite college project with Admin and User modules. Data is stored in browser Local Storage.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder and open it in VS Code.
3. In the terminal, run:
   npm install
   npm run dev
4. Open the local URL printed by Vite.

## Features
- React + Vite frontend and React Router navigation
- User signup, login, logout and protected dashboard
- Admin dashboard with car and user management
- Browse/search/filter cars
- Create and cancel rental bookings
- Local Storage persistence
- Responsive layout
- Vercel SPA rewrite configuration

## Deploy to Vercel
1. Push the project to a GitHub repository.
2. In Vercel, import that repository.
3. Framework preset: Vite
4. Build command: npm run build
5. Output directory: dist
6. Deploy.

## Important project limitation
This is a frontend academic demonstration. Local Storage is not secure authentication: passwords are stored in the browser and users can modify data using developer tools. Do not use real personal information or deploy this as a production rental service. A real system needs a secure backend, database, server-side authorization and payment integration.
